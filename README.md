# Лабораторна робота №7. Завантаження даних з публічного API та відображення на сторінці

## Дисципліна: WEB-програмування

**Виконала:** студентка групи КН-31 Білецька Христина  
**ВСП «Фаховий коледж інформаційних технологій НУ „Львівська політехніка“»**  
**Викладач:** Скалоцький Роман Андрійович

---

### 📌 Мета роботи

Навчитися взаємодіяти із зовнішніми серверами за допомогою протоколу HTTP, виконувати GET-запити за допомогою функції `fetch()`, обробляти асинхронні операції за допомогою `async/await`, перетворювати JSON-відповіді в масиви JavaScript та динамічно відображати отримані дані у DOM-структурі вебпроєкту «Акустична варта».

---

### 🛠 Виконане завдання

1. **Створення тестового API:** На платформі MockAPI створено проєкт та ресурс `sensors`, заповнений записами сенсорів (з полями `id`, `name`, `district`, `noiseLevel`, `status`).
2. **Асинхронний запит:** Реалізовано асинхронну функцію завантаження даних, яка використовує `fetch(API_URL)` для отримання списку сенсорів із сервера.
3. **Обробка відповіді:** Додано перевірку успішності запиту через властивості `response.ok` та `response.status`, а також конвертацію тіла відповіді за допомогою `await response.json()`.
4. **Рендеринг даних:** Написано функцію `renderSensors()`, яка очищує контейнер та динамічно формує HTML-картки для кожного сенсора з урахуванням його статусів.
5. **Обробка помилок:** Застосовано блок `try...catch` для перехоплення мережевих або серверних помилок із виведенням повідомлень у консоль та інтерфейс.

---

### 💡 Відповіді на контрольні питання

1. **Що таке API?**  
   Application Programming Interface — програмний інтерфейс, який дозволяє одній програмі взаємодіяти з іншою (наприклад, вебсторінка запитує дані у віддаленого сервера).
2. **Що таке endpoint?**  
   Конкретна адреса (шлях) у межах API, за якою можна отримати або змінити певні дані (наприклад, `/api/v1/sensors`).
3. **Для чого використовується HTTP GET?**  
   Для отримання (читання) даних із сервера без зміни їхнього стану.
4. **Що повертає `fetch()`?**  
   Promise (обіцянку), яка резолвиться в об’єкт `Response`, що представляє відповідь на запит.
5. **Що знаходиться у змінній `response` після `await fetch()`?**  
   Об’єкт відповіді `Response`, який містить статус запиту, заголовки, але ще не саме тіло даних у форматі JSON.
6. **Для чого використовується `response.json()`?**  
   Для зчитування тіла відповіді HTTP та перетворення його з текстового формату JSON у зручний масив або об’єкт JavaScript.
7. **Чому в типовому GET-запиті використовуються два `await`?**  
   Перший `await` чекає завершення мережевого запиту і отримання HTTP-відповіді від сервера, а другий — завершення читання й парсингу тіла відповіді з JSON у JavaScript-структуру.
8. **Що означає `response.ok`?**  
   Логічне значення (`true`, якщо HTTP-статус у діапазоні 200–299, і `false` у випадку помилок на кшталт 404 чи 500).
9. **Де у DevTools можна побачити HTTP-запит?**  
   На вкладці **Network** (Мережа) у розділі запитів (Fetch/XHR).
10. **Для чого потрібен `try/catch`?**  
    Для безпечного перехоплення та обробки винятків (помилок), які можуть виникнути під час виконання асинхронного коду (наприклад, зникнення інтернету чи помилка сервера).
